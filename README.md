
# TaskTrack

A command-line task management application built using Java.

## Features
- Add and view tasks
- Mark tasks as completed
- Delete tasks
- Track completed and pending tasks
- Validate user input

## Technologies
- Java
- Object-Oriented Programming
- ArrayList
- Java Collections Framework

## How to Run
1. Install Java 11 or later.
2. Compile using `javac TaskTrack.java`.
3. Run using `java TaskTrack`.
